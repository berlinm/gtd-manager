How to use this system

A quick reference for the GTD workflow as implemented here.

The four steps

1. Capture

Use the bar at the top of every page to dump anything on your mind into the Inbox. No deciding, just capturing. Speed matters here.

2. Clarify

Process each inbox item one at a time: decide what it is and what to do with it. Pick one of the dispositions below. Never leave items half-processed.

3. Organize

Clarified items land in the right list automatically. Use the sidebar to navigate: Next Actions, Projects, Waiting For, Agendas, Someday/Maybe, Reference.

4. Review

Do a short Daily Review each morning to orient yourself. Do a full Weekly Review once a week to keep the whole system current.

Inbox dispositions

When you clarify an inbox item, pick the destination that fits:

DispositionWhen to use itWhere it goes
Trash it Not needed and never will be Archived; no active record created
Done immediately Takes under two minutes to do right now Archived; no active record created
Someday / maybe Worth revisiting but not a current commitment Someday/Maybe list
Save as reference Useful information, no action required Reference library
Single next action One concrete physical step; no multi-step project Next Actions list
Action in a project A step belonging to an existing project Added to the chosen project
New project Outcome requiring more than one action Projects list; first action created
Delegate it Waiting on someone else to deliver something Waiting For list

Item types

Next Action
A single, concrete physical step. Should be specific enough that you can start without further planning. Examples: "Email Sarah about the report", "Call dentist to reschedule". Not a vague task like "Work on project".
Project
Any outcome that requires more than one action to complete. A project without a next action is stuck — the system will flag it. Keep projects named as outcomes: "Website launched", not "Website".
Waiting For
A commitment you are tracking that depends on someone else. Set a follow-up date so you remember to check in. Use the expected by date for when you expect delivery, and follow-up on for when you plan to nudge.
Agenda Item
Something to raise with a specific person or in a specific meeting. Not a next action — no date fields. Mark it raised once you have discussed it.
Someday / Maybe
Ideas and possibilities you want to keep visible without committing to them. Reviewed during the Weekly Review. Promote to a project when the time is right.
Reference
Information you may need later. No action associated with it. Supports Markdown formatting. Searchable by title and body.
Meeting
A recurring meeting (the entity, not a single occurrence). Start a session each time it happens to capture notes and see agenda items for that meeting.
Meeting Note
Captured during a session — works like an inbox item. Process it after the meeting closes using the same dispositions as the regular inbox.

Date fields on Next Actions

Three separate date fields serve distinct purposes. They are never interchangeable:

FieldMeaningUse when
Available from
(defer_until)		 Action is unavailable before this date You can not start it until a future date — waiting for something to happen first
Scheduled for Action must occur on this specific date and time An appointment, a call at a specific time, something with a hard start
Deadline Must be completed no later than this date A real external commitment with a hard consequence for missing it — not a self-imposed target

Ordering rule: Available from ≤ Scheduled for ≤ Deadline. The system will reject invalid combinations when editing.

Reviews

Daily Review
A quick morning orientation. Check what's scheduled today, what's due, whether any follow-ups need a nudge, and whether any projects are stuck. End by selecting a short focus list for the day. The focus list is temporary — it clears when you start the next daily review or manually clear it.
Weekly Review
A thorough audit of the whole system. Nine steps: clear inbox, review stuck and on-hold projects, review active next actions, check deadlines, update waiting-for follow-ups, review someday/maybe list, check agenda items, scan upcoming deadlines. Aim to do this once a week on a fixed day.

Keyboard shortcut

Press / anywhere to jump to the capture bar. Press Escape to leave it.
